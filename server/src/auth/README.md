# Модуль auth (зарезервирован)

Назначение будущего модуля:

- Discord OAuth2 Authorization Code Flow;
- проверка состояния и ролей участника Discord-сервера MoscowRoleplay;
- создание и проверка серверных сессий;
- связывание Discord-аккаунта с Roblox-аккаунтом;
- выдача краткоживущих токенов для клиента.

На текущем этапе модуль **не реализован**. Запрещено добавлять фиктивные OAuth-эндпоинты, поддельные токены и доверять данным клиента о ролях.

Будущие правила:

- токены и client secret никогда не попадают в логи и renderer Electron;
- состояние OAuth проверяется на сервере;
- права определяются на сервере по актуальным данным, а не по сообщению клиента;
- секреты Discord хранятся только в переменных окружения или Docker secrets.
