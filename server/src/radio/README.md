# Модуль radio

Реализован на этапе 5/5.

Назначение:

- радиоканалы общего назначения и государственных структур;
- проверка права на канал на сервере;
- роли могут выдаваться на нескольких Discord-серверах;
- режим `both-dual`: радио не заменяет proximity;
- одна передача на канал;
- ограничение длительности передачи.

Файлы:

- `channels.js` — загрузка и валидация `server/config/radio-channels.json`;
- `engine.js` — участники, говорящий, Consumers, таймер передачи.

Формат канала:

```json
{
  "id": "police",
  "name": "Полиция",
  "description": "Канал сотрудников полиции",
  "priority": 1,
  "access": [
    { "label": "Основной сервер", "guildId": "123456789012345678", "roleIds": ["234567890123456789"] },
    { "label": "Второй сервер", "guildId": "345678901234567890", "roleIds": ["456789012345678901"] }
  ]
}
```

Правила:

- пустой `access` — открытый канал для любого авторизованного пользователя;
- непустой `access` — нужна хотя бы одна роль хотя бы в одной группе доступа;
- `guildId` группы должен входить в `DISCORD_GUILD_ID` или `DISCORD_ROLE_GUILD_IDS`;
- роли проверяются через Discord Bot API, бот должен состоять на каждом сервере;
- устаревшее поле `roleIds` без `guildId` поддерживается и проверяется на всех настроенных серверах;
- клиент не может назначить себе канал или роль;
- клиенту не отправляются ID ролей и серверов, только признак `restricted`;
- занятость канала проверяется повторно после асинхронной проверки доступа;
- при начале передачи Consumers создаются всем участникам канала;
- при завершении, таймауте или отключении Consumers закрываются;
- выход из канала освобождает говорящего;
- состояние хранится в памяти и не пишется в PostgreSQL на каждое событие;
- без `DISCORD_BOT_TOKEN` открытые каналы работают, закрытые недоступны.

Параметры: `RADIO_ENABLED`, `RADIO_CHANNELS_FILE`, `RADIO_MAX_TRANSMISSION_MS`, `DISCORD_GUILD_ID`, `DISCORD_ROLE_GUILD_IDS`.

Подробное описание формата и примеры: `server/config/README.md`.
