# Модуль radio (зарезервирован)

Назначение будущего модуля:

- радиоканалы общего назначения;
- отдельные каналы государственных структур;
- проверка права на канал на сервере;
- управление состоянием передачи (PTT) и приоритетами;
- ограничение количества одновременных передач.

На текущем этапе модуль **не реализован**. Запрещено имитировать радиосвязь и PTT.

Будущие правила:

- принадлежность к каналу и право передачи проверяются на сервере;
- клиент не может назначить себе канал или роль;
- состояние каналов хранится в памяти и не пишется в PostgreSQL на каждое событие;
- при отключении клиента его передача принудительно завершается.
