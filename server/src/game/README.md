# Модуль game

Реализован на этапе 5/5.

Назначение:

- опрос PRC ER:LC API V2;
- получение состава игроков и координат X/Z;
- хранение снимка игрового сервера в памяти;
- определение устаревания данных;
- уведомление signaling об изменении игрового состояния.

Файлы:

- `poller.js` — единственный опросчик с backoff и соблюдением лимитов;
- `state.js` — снимок, события `PLAYER_JOINED`, `PLAYER_UPDATED`, `PLAYER_LEFT`.

Правила:

- одновременно выполняется не более одного запроса;
- пропущенные циклы не накапливаются;
- `Retry-After` и заголовки лимитов соблюдаются;
- при повторном отказе в ключе опрос останавливается;
- ошибка не превращается в пустой снимок;
- координаты и временные метрики не сохраняются в PostgreSQL;
- клиент не может подтвердить своё нахождение на сервере.

Без `PRC_SERVER_KEY` или при `GAME_POLL_ENABLED=false` модуль отключается с предупреждением, Proximity Voice не работает.
