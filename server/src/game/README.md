# Модуль game (зарезервирован)

Назначение будущего модуля:

- проверка нахождения игрока на сервере ER:LC через PRC API V2;
- получение сведений о Roblox-аккаунте;
- сопоставление Roblox-аккаунта с Discord-аккаунтом;
- кэширование результатов проверки с разумным временем жизни;
- защита от подмены клиентом своего Roblox-идентификатора.

На текущем этапе модуль **не реализован**. Запрещено имитировать ответы PRC API, придумывать поля API и сохранять игровые координаты в PostgreSQL при каждом обновлении.

Будущие правила:

- все ответы внешних API валидируются;
- учитываются таймауты, ограничения частоты и ошибки внешнего сервиса;
- клиент не может самостоятельно подтвердить своё нахождение на сервере;
- персональные данные не логируются.
