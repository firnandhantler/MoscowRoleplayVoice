# Модуль voice (зарезервирован)

Назначение будущего модуля:

- создание mediasoup Worker, Router и WebRTC Transport;
- выдача клиенту параметров подключения;
- управление аудиопроизводителями и потребителями;
- согласование кодеков и параметров RTP;
- изоляция голосовых комнат и каналов.

На текущем этапе модуль **не реализован**. Запрещено создавать фиктивные Worker/Router, поддельные SDP-ответы и имитацию передачи голоса.

## Подготовленная конфигурация

В `.env` уже зарезервированы:

- `MEDIASOUP_LISTEN_IP` — адрес прослушивания внутри контейнера;
- `MEDIASOUP_ANNOUNCED_IP` — публичный IP сервера, который будет сообщаться клиентам;
- `MEDIASOUP_RTC_MIN_PORT` и `MEDIASOUP_RTC_MAX_PORT` — диапазон UDP-портов;
- `MEDIASOUP_WORKER_COUNT` — количество Worker-процессов.

Docker Compose публикует этот диапазон UDP-портов. При установке `mediasoup` скачивает заранее собранный Worker для поддерживаемой платформы; при отсутствии готового бинарника может потребоваться локальная сборка C++. Python в проект не добавляется. Для проверки Linux-совместимости используйте Docker или WSL2.

На текущем этапе mediasoup установлен как зависимость, но Worker, Router и Transport ещё не создаются. `MEDIASOUP_ANNOUNCED_IP` можно оставить пустым; публичный IP потребуется указать перед развёртыванием голосового модуля на VPS, но не `127.0.0.1`.
