# Модуль proximity

Реализован на этапе 5/5.

Назначение:

- расчёт слышимости по координатам PRC;
- spatial grid и сравнение квадратов расстояний;
- гистерезис на границе радиуса;
- дифференциальное создание и закрытие Consumers;
- разрыв связей при устаревшем снимке и отключении игрока.

Файл: `engine.js`.

Правила:

- геометрия считается только на сервере;
- клиентские координаты не используются;
- координаты не сохраняются в PostgreSQL;
- обновления дифференциальные, а не полная перестройка графа;
- число соседей ограничено `PROXIMITY_MAX_NEIGHBORS`;
- при устаревании `GameState` связи закрываются, а не считаются пустыми;
- при отключении пользователя его состояние удаляется.

Параметры: `PROXIMITY_MAX_DISTANCE`, `PROXIMITY_HYSTERESIS`, `PROXIMITY_UPDATE_INTERVAL_MS`, `PROXIMITY_MAX_NEIGHBORS`.
