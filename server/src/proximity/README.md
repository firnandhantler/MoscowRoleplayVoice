# Модуль proximity (зарезервирован)

Назначение будущего модуля:

- расчёт слышимости игроков по расстоянию;
- учёт препятствий и зон, если это потребуется;
- обновление состояния в оперативной памяти;
- передача изменений в голосовой модуль без записи координат в PostgreSQL на каждом тике.

На текущем этапе модуль **не реализован**. Запрещено имитировать расчёт близости и передачу голоса.

Будущие правила:

- координаты игроков считаются временными данными и не сохраняются в PostgreSQL при каждом обновлении;
- частота обновлений ограничивается, чтобы не перегружать 1 vCPU и 2 GB RAM;
- клиентские координаты не считаются доверенными без серверной проверки;
- при отключении игрока его временное состояние удаляется.
