# Общие контракты сервера

`protocol.js` — канонический источник общего протокола: типы сообщений, коды ошибок, перечисления и константы.

Копия для клиента находится в `app/shared/protocol.js`. Редактировать нужно только `protocol.js` в этой папке, затем синхронизировать копию:

```powershell
cd server
npm run shared:sync
npm run shared:check
```

`npm run verify` включает `shared:check` и завершается ошибкой, если копии различаются. Если папка `app` отсутствует (сервер развёрнут отдельно), проверка пропускается.
