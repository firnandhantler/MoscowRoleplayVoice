# Инициализация PostgreSQL в Docker

Файл `01-create-app-role.sh` выполняется официальным образом PostgreSQL только при **первом создании** пустого тома `postgres_data`.

Он создаёт отдельную роль приложения:

- суперпользователь `POSTGRES_SUPERUSER` (по умолчанию `postgres`) используется только для администрирования и создания резервных копий;
- приложение подключается ролью `POSTGRES_USER` (по умолчанию `mrv_app`) с паролем `POSTGRES_PASSWORD`;
- роль приложения получает право подключения к базе и создания таблиц в схеме `public`.

## Важно

- Если том уже инициализирован, изменения паролей в `server/.env` не применяются автоматически. Пароль нужно изменить через `psql` или пересоздать том (удаление тома уничтожит данные).
- Не публикуйте PostgreSQL наружу. В основном `server/docker-compose.yml` порт базы не публикуется.
- Для локальной разработки на Windows используйте `server/docker-compose.dev.yml`, который публикует порт только на `127.0.0.1`.
