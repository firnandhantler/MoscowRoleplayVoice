# Миграции PostgreSQL

Миграции применяются командой:

```powershell
cd server
npm.cmd run migrate
```

В Docker:

```powershell
docker compose exec server node server/src/database/migrate-cli.js
```

## Правила

1. Имя файла: `NNNN_краткое_описание.sql`, например `0002_accounts.sql`.
2. Порядок применения определяется лексикографической сортировкой имён.
3. Уже применённую миграцию **нельзя изменять**: контрольная сумма хранится в таблице `schema_migrations`.
4. Для изменения схемы создаётся новая миграция.
5. Каждая миграция выполняется в отдельной транзакции. Не добавляйте в SQL-файл `BEGIN`, `COMMIT` или `ROLLBACK`.
6. Не добавляйте в миграции игровые координаты, временные метрики и другие быстро меняющиеся данные.
7. Перед применением на сервере проверьте миграцию на локальной базе.

Таблица `schema_migrations` создаётся автоматически при первом запуске механизма миграций. На текущем этапе бизнес-схема ещё не проектируется.
