Голосовая система для Roblox ER:LC

Этап 1 · фундамент

Безопасный каркас клиента

Клиент готов к следующему этапу

Сейчас здесь нет передачи голоса, авторизации и радиоканалов. Это намеренно: на первом этапе создаётся только безопасная основа, на которую будут опираться голосовые модули.

Что уже заложено

  • contextIsolation: true
  • nodeIntegration: false
  • Изолированный preload.js с минимальным API
  • Запрет внешних переходов и новых окон
  • Запрет разрешений браузера по умолчанию
  • CSP без внешних источников

Что появится позже

  • Авторизация через Discord
  • Связка Discord и Roblox
  • Proximity Voice
  • Радиоканалы и PTT
  • mediasoup-client и Web Audio API
Важно: клиент не подключён к серверу и не запрашивает доступ к микрофону. Это будет реализовано на следующих этапах после серверной авторизации и проверки прав.
