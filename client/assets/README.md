# Ресурсы клиента

В этой папке будут храниться иконки и другие статические ресурсы Electron-клиента.

На текущем этапе бинарные ресурсы не добавляются. Будущие файлы:

- `icon.ico` — иконка Windows-приложения;
- `icon.png` — иконка для окна и установщика;
- `tray.png` — иконка системного трея, если появится трей.

Не добавляйте сюда пользовательские данные, токены и секреты.
